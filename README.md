# abukhaleed-website

موقع أبو خالد لشراء وبيع المكيفات والسكراب والألمنيوم والأثاث المستعمل في جدة ومكة المكرمة ورابغ.

## الموقع الرسمي

https://abu-khalid.netlify.app/

## عن النشاط

أبو خالد متخصص في شراء وبيع:

- المكيفات المستعملة والخربانة وسكراب المكيفات والكمبروسرات
- النحاس والألمنيوم والحديد والكيابل والأسلاك
- الأجهزة الكهربائية والمطابخ والمعدات المنزلية
- معدات المطاعم والكافيهات
- الأثاث المنزلي والمكتبي المستعمل
- سكراب المصانع والمستودعات والمشاريع والورش
- الهياكل والمنتجات المعدنية

## نطاق الخدمة

- جدة (جميع الأحياء)
- مكة المكرمة
- رابغ

## التقنيات المستخدمة

- HTML5 — هيكل الصفحة
- CSS3 — التصميم والتجاوب (Responsive)
- JavaScript (Vanilla) — التفاعلات والترجمة والوضع الليلي
- Font Awesome 6 — الأيقونات
- Google Fonts (Cairo) — الخطوط العربية
- WhatsApp URL API — استقبال الطلبات
- Netlify — الاستضافة
